# Test Badges 🏅

A small practice repository for learning GitHub workflows and unlocking profile achievements.

## What this repo is for

- Practising branches, commits and pull requests
- Trying out co-authored commits
- Earning GitHub achievements along the way

## Achievements targeted

| Badge | How it's earned |
|-------|-----------------|
| 🎲 YOLO | Merging a pull request without a review |
| 👯 Pair Extraordinaire | Merging a pull request with a co-authored commit |
| 🦈 Pull Shark | Getting pull requests merged |

## How it works

1. Create a new branch and make a small change
2. Commit it with a `Co-authored-by:` line
3. Open a pull request and merge it without requesting a review
